# Инструкция по развертыванию и использованию Telegram-бота

## Описание

Данный Telegram-бот разработан для заказа материалов с возможностью прикрепления фотографий и отправки сообщений. Бот имеет интуитивно понятный интерфейс с кнопками навигации и различными функциональными разделами.

## Требования

- Python 3.10 или выше
- Установленные зависимости (см. раздел "Установка")
- Токен Telegram-бота, полученный от @BotFather

## Структура проекта

```
telegram_bot/
├── database/              # Модуль для работы с базой данных
│   ├── __init__.py
│   └── db.py
├── handlers/              # Обработчики команд и сообщений
│   ├── __init__.py
│   ├── command_handlers.py
│   └── order_handlers.py
├── keyboards/             # Клавиатуры для взаимодействия с пользователем
│   ├── __init__.py
│   └── keyboards.py
├── utils/                 # Вспомогательные функции
│   ├── __init__.py
│   └── helpers.py
├── .env.example           # Пример файла с переменными окружения
├── main.py                # Основной файл бота
├── run_bot.py             # Скрипт для запуска бота
└── test_bot.py            # Тесты для проверки компонентов бота
```

## Установка

1. Клонируйте репозиторий или распакуйте архив с кодом:

```bash
git clone <url-репозитория>
# или
unzip telegram_bot.zip
```

2. Перейдите в директорию проекта:

```bash
cd telegram_bot
```

3. Установите необходимые зависимости:

```bash
pip install python-telegram-bot python-dotenv
```

4. Создайте файл `.env` на основе `.env.example` и добавьте токен вашего бота:

```
TOKEN=your_telegram_bot_token_here
ADMIN_IDS=123456789,987654321  # ID администраторов (необязательно)
DEBUG=True
DATABASE_URL=sqlite:///bot_database.db
```

## Запуск

Для запуска бота выполните:

```bash
python run_bot.py
```

Скрипт автоматически проверит наличие файла `.env` и, если его нет, предложит ввести токен бота и другие параметры.

## Тестирование

Для запуска тестов выполните:

```bash
python test_bot.py
```

Тесты проверят основные компоненты бота: настройку окружения, модуль базы данных, модуль клавиатур и модуль утилит.

## Функциональность бота

### Основные команды

- `/start` - Начать работу с ботом
- `/help` - Показать справочную информацию
- `/menu` - Показать главное меню

### Основные функции

1. **Ввод кода товара**
   - При первом запуске бот запрашивает код товара
   - Код проверяется на корректность (должен содержать только цифры)

2. **Главное меню**
   - Прикрепить фото
   - Отправить заказ без фото
   - Инструкция по оформлению
   - Мегабук (справочник)
   - Нужна другая информация?
   - Заказ фото/видео
   - Фотосет

3. **Заказ с фото**
   - Пользователь может прикрепить фотографию и добавить описание
   - Заказ сохраняется в базе данных
   - Администраторы получают уведомление о новом заказе

4. **Заказ без фото**
   - Пользователь вводит описание заказа
   - Заказ сохраняется в базе данных
   - Администраторы получают уведомление о новом заказе

5. **Инструкция по оформлению**
   - Предоставляет информацию о правилах оформления заказов
   - Возможность скачать файлы с инструкциями

6. **Мегабук**
   - Предоставляет ссылку на справочные материалы

7. **Дополнительная информация**
   - Пользователь может запросить дополнительную информацию
   - Запрос обрабатывается и сохраняется

8. **Заказ фото/видео**
   - Пользователь может заказать фото или видео контент
   - Заказ сохраняется в базе данных
   - Администраторы получают уведомление о новом заказе

9. **Фотосет**
   - Переход к другому боту для работы с фотосетом

### Навигация

В каждом меню доступны кнопки:
- "Назад" - возврат в предыдущее меню
- "Главное меню" - возврат на стартовую страницу

## Настройка для администраторов

Для получения уведомлений о новых заказах, добавьте ID администраторов в файл `.env`:

```
ADMIN_IDS=123456789,987654321
```

ID можно узнать, отправив сообщение боту @userinfobot.

## Развертывание на сервере

Для постоянной работы бота рекомендуется развернуть его на сервере:

1. Загрузите код на сервер
2. Установите зависимости
3. Создайте файл `.env` с токеном бота
4. Настройте автозапуск (например, с помощью systemd или supervisor)

Пример конфигурации для systemd:

```ini
[Unit]
Description=Telegram Bot Service
After=network.target

[Service]
User=username
WorkingDirectory=/path/to/telegram_bot
ExecStart=/usr/bin/python3 /path/to/telegram_bot/run_bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

## Устранение неполадок

### Бот не отвечает

1. Проверьте, что токен бота указан правильно в файле `.env`
2. Убедитесь, что бот запущен и работает
3. Проверьте логи на наличие ошибок

### Ошибки импорта модулей

1. Убедитесь, что структура проекта не нарушена
2. Проверьте, что все файлы `__init__.py` присутствуют в пакетах

### Проблемы с базой данных

1. Проверьте права доступа к директории с базой данных
2. Убедитесь, что SQLite установлен в системе
